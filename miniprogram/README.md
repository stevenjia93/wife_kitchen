# 老婆点菜老公做小程序版

原生微信小程序目录，AppID 为 `wxf4ebe7e96ab81d1e`，首页为 `pages/home/index`。

## 当前架构

- 所有接口统一走 `globalData.apiBase`。
- 生产后端为阿里云中国内地 ECS 上的 Express。
- 菜单数据保存到阿里云 RDS PostgreSQL。
- 不再依赖 Supabase Edge Function、Supabase 客户端或 Vercel。
- 阿里云百炼的千问 VL 和图像生成模型用于照片热量分析及分享图生成，图片请求不再发往境外 OpenAI 接口。
- `wx.login` 只上传一次性登录码；服务端使用微信用户标识建立会话，并按家庭成员关系保护菜单读写。
- 用户可以创建多个家庭，通过小程序分享卡片邀请老公或好友加入；家庭邀请有期限和使用次数限制。

完成备案和 HTTPS 后，在 `app.js` 中填写唯一的生产 API 域名：

```js
apiBase: "https://api.wife-kitchen.com"
```

## 微信后台域名

在开发管理 → 开发设置 → 服务器域名中，将上述 HTTPS 域名配置为 `request` 合法域名。域名必须完成 ICP 备案/阿里云接入备案，证书有效且支持 TLS 1.2 或以上。不要填写 IP、端口、路径，也不要保留 Supabase/Vercel 域名。

当前小程序不用 `web-view`，不需要配置业务域名。

## 隐私保护配置

- 使用相册（仅写入）：保存用户主动生成的餐桌热量分享图。
- 读取剪切板：用户主动点击复制时，将菜谱链接或采购清单写入剪切板；代码不会读取原有剪切板内容。
- 收集选中的照片或视频信息：处理用户主动选择的餐桌照片；当前仅选择图片。
- 第三方插件/SDK：不增加，小程序前端未接入第三方插件或 SDK。
- 账号注销：选择“小程序中未注册账号”。
- 信息存储：选择“实现处理目的所必要的最短时间”。
- 超出原用途时再次告知：弹窗。
- 联系方式：`stevenjia93@gmail.com`。
- 补充文档：上传 `privacy-notice.txt`。
